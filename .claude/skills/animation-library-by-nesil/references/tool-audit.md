# Tool Audit — Nesil's Sourced References

Honest read on the specific sites Nesil shared, checked directly (Sept 2026). Use this table to decide whether something is safe to ship from, or moodboard-only.

| Site | What it actually is | Cost | Fit / caveats |
|---|---|---|---|
| **vgpu.sh/examples** | Vercel Labs' open-source WebGPU library. Real, technically serious: raymarched black holes, FFT ocean simulation, radiance-cascade global illumination, fluid solvers, Three.js↔WGSL interop, ONNX/ML-on-GPU demos. Graphics-research grade, not a design showcase. | Free, open source (GitHub) | Reference for what a specialist creative developer should eventually be capable of. Don't brief this directly to a generalist dev — it's advanced. Good to point to when scoping a genuinely ambitious 3D/shader hire. |
| **threeui.com** | Commercial component marketplace — copy-ready Three.js/WebGL hero sections, backgrounds, buttons, text/motion pieces, full landing-page templates. Framework-agnostic JS. Has an MCP server so a coding agent can pull components directly. | Free "Community" tier + paid Pro/lifetime | Legitimate, maintainable. Good for shipping fast on marketing-site 3D work. |
| **skiper-ui.com** | 73+ React/Next.js components, shadcn-compatible. Tagged scroll effects, hover effects, animations, interactive components. UI-animation-first, not 3D. | Free + paid tiers | Best fit for product UI work (dashboards, LMS/CMS) rather than marketing spectacle. Integrates naturally if the dev stack already uses shadcn/Tailwind — likely upGrad's case. |
| **animmasterlib.dev** | 300 components explicitly described as **"rebuilt with clean code from top-tier websites"** — i.e. cloned effects from other people's (often award-winning) sites. Sold as a one-time pack. Categorized taxonomy is genuinely useful (66 scroll, 26 hero, 23 sliders, 22 3D, 21 nav menus, 20 hover, 20 mouse, 18 WebGL shaders, 14 page transitions, 14 text, 11 SVG, 10 background, 10 grid, 10 physics). | $3–$20 one-time tiers | ⚠️ Marketing uses manipulative dark patterns (fake "try clicking again on your phone" urgency nudges). Components are explicit clones of others' work. Fine as a personal learning/category reference. **Do not ship components sourced here into a paid upGrad or Malayali Kada product without a clean rebuild** — both a code-quality and an IP-provenance concern. |
| **motionsites.ai** | Not components — **AI prompts** for Lovable/Bolt/Cursor/Claude that generate 3D/animated landing pages. Buying prompt text, not code. Upsells into a "Design Rocket" course. | Prompt marketplace + course upsell | Useful as a fast-prototyping shortcut via AI page-builders. Treat any output as a rough draft to rebuild properly — not launch-ready as-is. Marketing has aggressive-upsell patterns; discount accordingly. |
| **Awwwards collections** (e.g. du-haihang's WebGL-animations collection) | Curated lists of full award-nominated/winning sites. Each entry is a whole case study (agency, stack, craft), not an isolated effect. | Free to browse | Best used the way the build-playbook recommends: open a site in DevTools, throttle CPU, study *how* they sequence and protect performance — not just how it looks. |
| **Dribbble WebGL search** | Static shots/GIFs/short clips tagged "webgl" — designer concepts, often *not built* or built only as one-off demos with no visible code (e.g. an interactive tornado, a distortion slider by Unseen Studio, a mouse-parallax globe by 12 Studio). | Free to browse | Good for visual direction/vocabulary in a design review. No code behind most shots — moodboard input only, not implementation reference. |
| **LottieFiles** | Large free/paid Lottie JSON animation marketplace. | Free + paid | Straightforward — good for onboarding/empty-state motion graphics per the Lottie-vs-Rive distinction in `principles-and-categories.md`. |

## The one-line rule for using this table

- **Ship-ready sources:** threeui.com, skiper-ui.com, LottieFiles, Awwwards (as reference, not asset-copy), your own R3F/GSAP builds.
- **Prototype/learning only, rebuild before shipping:** animmasterlib.dev, motionsites.ai outputs, anything traced to a Dribbble shot.
- **Specialist calibration reference:** vgpu.sh.
